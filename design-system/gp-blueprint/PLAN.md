# GP Blueprint design plan

Use Midnight #0F0F23, Panel #1B1B30, Raised #27273B, White #F8FAFC, Lavender #9994F5 and Green #22C55E. Righteous gives the display title a musical character. Poppins makes names, timing data and controls easy to scan.

```
Desktop                                Mobile
Brand                    Changelog     Brand       Changelog
Title             Arrangement sample   Title
Reference         Blueprint output     Arrangement sample
AI settings       Style / Stems        Reference and AI settings
Generate          Structure / Lyrics   Blueprint output
```

The changelog shares navigation, canvas and type, with dated entries aligned to one reading column. Keep both pages left-aligned. The song arrangement is the focal point and uses the example's real section and duration values. Use compact status, card headers and clearly labeled copy controls.

## Brief check

The generated showcase pattern would delay work behind feature descriptions. Keep the actual reference form and example output directly below the introduction, with a link to the output for narrow screens. The arrangement previews the existing sample and uses no new audio, content service or generator. Keep the artist, song, lyrics, YouTube link, MusicAtlas, key, model, generation, stop, clear, copy and song-spec controls connected to their existing handlers. Keep Suno and Mozart results intact. Use responsive stacking, 14px supporting copy and tabular figures for numeric metadata. Verify both routes and populated output at 390px and 1440px.
